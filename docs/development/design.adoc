== Schnittstellen (Mit KI vervollständigt)
:toc:
:toclevels: 3

=== User (userRouter)

==== POST /register
* *Summary:* Register User
* *Beschreibung:* Registriert einen neuen Benutzer.
* *Request Body:* `application/json` (<<schema-UserSchema,UserSchema>>)
* *Antworten:*
** `200 OK` – Registrierung erfolgreich (Message + user_id)
** `400 Bad Request` – z.B. Passwort leer / Duplicate Email/Username
** `422 Unprocessable Entity` – Validierungsfehler

==== POST /login
* *Summary:* Login
* *Beschreibung:* OAuth2 Password Login; setzt Cookie `access_token` und liefert Token zurück.
* *Request Body:* `application/x-www-form-urlencoded` (OAuth2PasswordRequestForm)
* *Antworten:*
** `200 OK` – `{ message, access_token, token_type }`
** `401 Unauthorized` – falsche Daten / User nicht aktiv

==== GET /users
* *Summary:* Get All Users
* *Beschreibung:* Liefert alle Benutzer.
* *Antworten:* `200 OK`

==== GET /users/me
* *Summary:* Get Current User
* *Security:* `Bearer` (active user) via `check_active`
* *Beschreibung:* Gibt `{username,email,role}` des eingeloggten Users zurück.
* *Antworten:* `200 OK`, `401 Unauthorized`

==== POST /logout
* *Summary:* Logout
* *Beschreibung:* Löscht Cookie `access_token`.
* *Antworten:* `200 OK`

==== GET /verify/{token}
* *Summary:* Verify User
* *Beschreibung:* Verifiziert Account anhand Verify-Token.
* *Pfadparameter:* `token` (string)
* *Antworten:* `200 OK`, `400 Bad Request`, `404 Not Found`, `409 Conflict`, `422 Unprocessable Entity`

==== GET /secured
* *Summary:* Get Users (secured)
* *Security:* `Bearer` (active user) via `check_active`
* *Beschreibung:* Liefert User-Liste (gesichert).
* *Antworten:* `200 OK`

==== GET /adminsonly
* *Summary:* Get Users (admin only)
* *Security:* `Bearer` (admin) via `check_admin`
* *Beschreibung:* Liefert User-Liste (nur Admin).
* *Antworten:* `200 OK`

==== GET /users/me/company
* *Summary:* Check my company
* *Security:* `Bearer` (active user) via `check_active`
* *Beschreibung:* Gibt zurück, ob User in einer Gesellschaft ist und IDs der Companies.
* *Antworten:* `200 OK`, `401 Unauthorized`


=== Company (companyRouter)

==== GET /users/company
* *Summary:* Get company info
* *Security:* `Bearer` (active user)
* *Beschreibung:* Liefert die Company des Users (erste Company, falls mehrere).
* *Antworten:* `200 OK`, `404 Not Found`

==== POST /users/company
* *Summary:* Create company
* *Security:* `Bearer` (active user)
* *Beschreibung:* Erstellt eine Gesellschaft und verlinkt den User als Owner.
* *Request Body:* `CompanyCreateRequest`
* *Antworten:* `200 OK`, `400 Bad Request`

==== POST /users/company/vehicles
* *Summary:* Get company vehicles
* *Security:* `Bearer` (active user)
* *Beschreibung:* Liefert alle Vehicles der Company des Users (aktuell: erste Company).
* *Antworten:* `200 OK`, `400 Bad Request`, `401 Unauthorized`


=== Fahrzeuge (vehicleRouter)

==== GET /vehicles
* *Summary:* Get all vehicles
* *Beschreibung:* Liefert alle Vehicles gruppiert; aktualisiert ggf. Lieferstatus (in_delivery -> ready) serverseitig.
* *Antworten:* `200 OK`


=== Trassen (routeRouter)

==== GET /trasse/{route_uuid}
* *Summary:* Get route detail
* *Beschreibung:* Liefert Detailinfos einer Trasse inkl. Stops.
* *Pfadparameter:* `route_uuid` (UUID)
* *Antworten:* `200 OK`, `404 Not Found`

==== GET /trassen
* *Summary:* Get routes
* *Beschreibung:* Liefert alle Trassen (aggregiert + Stop-Infos).
* *Antworten:* `200 OK`


=== Ausschreibungen (tenderRouter)

==== GET /tender/open
* *Summary:* Get open tenders
* *Security:* `Bearer` (active user)
* *Beschreibung:* Liefert offene Ausschreibungen (ohne Contract).
* *Antworten:* `200 OK`, `500 Internal Server Error`


=== Shop (shopRouter, Prefix /shop)

==== GET /shop/vehicle-types
* *Summary:* List vehicle types
* *Security:* `Bearer` (active user)
* *Beschreibung:* Liefert Fahrzeugtypen im Shop, optional gefiltert.
* *Query-Parameter:*
** `kind` (optional, VehicleKind)
** `q` (optional, string Suche)
* *Antworten:* `200 OK`

==== GET /shop/vehicle-types/{type_id}
* *Summary:* Vehicle type details
* *Security:* `Bearer` (active user)
* *Beschreibung:* Liefert Details + Kompatibilitäten (via CouplingLink).
* *Pfadparameter:* `type_id` (int)
* *Antworten:* `200 OK`, `404 Not Found`

==== POST /shop/vehicle-types/{type_id}/lease
* *Summary:* Lease vehicle type
* *Security:* `Bearer` (active user)
* *Beschreibung:* Leased ein Vehicle für die (erste) Company des Users; reduziert Kapital + Bestand; setzt Lieferstatus.
* *Pfadparameter:* `type_id` (int)
* *Request Body:* `LeaseRequest` (enthält `leasing_model`)
* *Antworten:*
** `200 OK`
** `400 Bad Request` – z.B. keine Company, ungültiges Leasingmodell, nicht genug Kapital, keine passende Lok
** `404 Not Found` – Fahrzeugtyp nicht gefunden
** `409 Conflict` – Bestand = 0
** `500 Internal Server Error` – Details/Bestand fehlen oder DB-Fehler

=== [[schema-User]] User

* *Typ:* `object`

[cols="1,1,2",options="header"]
|===
| Feld
| Typ
| Beschreibung

| `id`
| `integer` \| `null`
| Interne ID des Benutzers.

| `email` (*required*)
| `string` (E-Mail)
| E-Mail-Adresse des Benutzers.

| `username` (*required*)
| `string`
| Anzeigename / Benutzername.

| `is_active`
| `boolean` (default: `false`)
| Gibt an, ob der Benutzer bereits aktiv ist.

| `role` (*required*)
| <<schema-Roles,Roles>>
| Rolle des Benutzers (`user` oder `admin`).

| `hashed_password` (*required*)
| `string`
| Passwort-Hash des Benutzers.
|===

|===

| Typ
| Beschreibung

== Security-Schemes

=== OAuth2PasswordBearer

* *Typ:* `oauth2` (Password Flow)

* *Token-URL:* `POST /login`

* *Scopes:* keine vordefiniert (leeres Objekt `{}` im Schema)

* Wird von folgenden Endpunkten verwendet:

** `GET /secured`
** `GET /adminsonly`
